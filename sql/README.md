# SQL Scripts

This directory contains all SQL scripts for database setup and management.

## Files

- `create_tables.sql` - Initial database schema creation
- `supabase_rls_policies.sql` - Row Level Security policies for Supabase Auth
- `supabase_clerk_rls_policies.sql` - Row Level Security policies for Clerk Auth
- `supabase_realtime_setup.sql` - Realtime subscriptions setup
- `disable_rls_temporarily.sql` - Temporary RLS disable for development
- `cleanup_duplicate_users.sql` - Clean up duplicate user records
- `update_usernames.sql` - Username update scripts

## Usage

Run these scripts in your Supabase SQL editor in the order appropriate for your setup needs.
